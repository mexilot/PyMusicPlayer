# MusicApp

A modern and customizable music player for Linux built with Python, PySide6 and QML.

MusicApp is designed for Linux desktop environments and provides a clean, transparent and customizable interface with MPRIS support and synchronized lyrics.

## Features

- MPRIS media player integration
- Play and pause controls
- Previous and next track controls
- Interactive playback progress bar
- Album artwork
- Song title, artist and album information
- Synchronized lyrics
- Automatic lyric scrolling
- Highlighted current lyric
- Transparent interface
- Customizable colors and styling
- Draggable application window
- QML-based interface
- Wayland-friendly

## Requirements

- Linux
- Python 3
- PySide6
- dbus-python
- Requests
- MPRIS-compatible media player

Recommended environment:

- Arch Linux or CachyOS
- Wayland
- Hyprland
- Firefox
- Spotify
